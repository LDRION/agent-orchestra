# Дорожная карта

## Сделано

**v0.1 — фундамент**
- Модульный монолит FastAPI, миграции Alembic, SQLite/PostgreSQL.
- Доступы: оргструктура, роли с allow/approval/deny, наследование по дереву, защита от эскалации, визы «четыре глаза».
- Шлюз моделей: Ollama, OpenAI-совместимые (OpenAI, YandexGPT, DeepSeek, OpenRouter, LM Studio, vLLM), Claude, Siberi; цепочки запасных моделей; политика выхода данных; маскирование ПДн; учёт вызовов.
- Оркестрация: план с зависимостями, ворота виз до и после плана, параллельный граф шагов, повторы, сводка, живые события, восстановление после перезапуска.
- Агенты проектной организации (11), версии промтов с публикацией через визу, импорт/экспорт `.md`.
- Аудит с хеш-цепочкой. Веб-интерфейс, лаунчер, Docker для сервера.

**v0.2 — знания и защита входа**
- База знаний: Word/PDF/текст, поиск с русским стеммингом, права по подразделениям, гриф; справка агентам до ответа.
- Песочница промтов: черновик против работающей версии на живой модели до публикации.
- Двухфакторный вход (TOTP), коды восстановления, список сессий, обязательный 2FA для управляющих на сервере.
- Дневные лимиты токенов на человека и на модель; расход «сегодня» по моделям и людям.
- Ротация мастер-ключа одной командой.

**v0.3 — интеграции и первый процесс**
- Слой интеграций: Битрикс24, 1С (OData), почта (SMTP), Telegram, исходящий и входящий вебхуки; демо-режимы; плагины.
- Действия систем — инструменты агентов: чтение в пределах грифа, запись — только предложение, выполнение человеком или по визе.
- Процесс «Протоколы»: правила с тестами, разбор через шлюз, проверка человеком, отправка в Битрикс24.
- Справочник сотрудников, отделов и проектов с загрузкой из Битрикс24.

**v0.4 — безопасность снаружи и внутри**
- Подтверждение паролем перед опасными действиями, защита от перебора внутри сессии, cookie `__Host-`.
- Закрыты пути эскалации: управление людьми с бОльшими правами, снятие запретов, перенос подразделений, роли шире своих.
- Временные роли и запросы доступа с визой того, кто вправе выдать роль.
- Периметр: Host, сети компании, общий предел запросов; вебхуки с меткой времени и защитой от повтора.
- SSRF: служебные адреса закрыты для моделей и интеграций, чтение сайтов — к проверенному IP; интернет агента выключен для конфиденциального и вебхуков.
- Центр безопасности: состояние защиты, неудачные попытки, все сессии, тревоги в Telegram/почту/вебхук.
- Логи без секретов, токен настройки — во фрагменте адреса.

**v0.5 — без допущений**
- Гонки: виза и запись во внешнюю систему выполняются ровно один раз при двойном нажатии и двух визах.
- Сеть: проверка адреса при каждом подключении у всех исходящих клиентов (DNS-rebinding), SMTP — тоже.
- Журнал: запрет правки на SQLite, заверенная метка конца вне базы (обрезка и откат видны), переподпись при ротации и восстановлении.
- Ротация мастер-ключа перешифровывает и секреты интеграций (раньше — нет).
- Вход: лимиты считают только неудачи (офис за NAT), IPv6 по /64; временный пароль — проверка на сервере; строже словарь паролей.
- Восстановление владельца из консоли, зашифрованные копии базы лаунчера, повтор вебхуков — в БД.
- Цепочка поставок: точные версии Python-зависимостей, образы по дайджесту, CI (тесты, bandit, pip-audit, npm audit, gitleaks), Dependabot.
- Docker: Caddy изолирован от базы, X-Forwarded-For — только от Caddy.
- Центр безопасности: лента изменений прав, ключей и настроек; проверка целостности журнала кнопкой.
